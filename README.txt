# Gaseosas Sol — Refajo de Kola Sol + Poker

## Archivos
- index.html: inicio + centro multimedia
- producto.html: ficha del producto
- campana.html: campaña y piezas visuales
- contacto.html: formulario
- style.css: diseño responsive y animaciones
- script.js: menú, animaciones, carga de logo, flyers, videos y formulario demo
- assets/: coloca aquí tus recursos permanentes

## Cómo usar
1. Abre `index.html` en Chrome, Edge o Firefox.
2. En Inicio, usa los botones de Logo, Flyers y Videos para previsualizar tus piezas.
3. Para dejar el logo fijo en el código, puedes reemplazar el contenido de `assets/` y modificar el HTML si lo deseas.
4. El formulario es solamente visual: para recibir mensajes necesitas conectarlo a un backend o servicio de formularios.

## Importante
La guía suministrada define el producto como "Refajo de Kola Sol + Poker", el público objetivo de 18 a 50 años y las presentaciones de lata de 350 ml y caja tetrapack. La guía deja campos de concepto creativo, eslogan, personalidad, estilo UX/UI y selección multimedia sin diligenciar; por eso esos aspectos fueron tratados aquí como decisiones de propuesta visual y no como datos oficiales del documento.
